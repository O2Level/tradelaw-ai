# Demo Data

This directory documents the built-in TradeLaw AI demo cases.

## Cases

1. `vietnam-po` - Vietnam buyer PO with arrival and buyer inspection balance risk.
2. `indonesia-ddp` - Indonesia DDP order with unclear import clearance, tax and port cost allocation.
3. `malaysia-quality` - Malaysia quality objection and unpaid balance evidence package scenario.

Use:

```bash
npm run demo:import
npm run demo:vietnam
npm run report:demo
```
